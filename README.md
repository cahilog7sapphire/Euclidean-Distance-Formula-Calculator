# ---Euclidean-Distance-Formula-Calculator---

# Description
This is a simple distance formula calculator, with an imported python math library.

# How to Run
Simply execute the code in a python compiler, it can be an online IDE, OnlineGDB, or an offline IDE, like Pycharm.

# Input Needed
Input the x-coordinate and y-coordinate from the first and second set of coordinates.

# Simple Output
Inputting (3,4) as your first set, and then (6,7) as your second set, the output will 4.24, the answer is also rounded off by 2 decimal places.
